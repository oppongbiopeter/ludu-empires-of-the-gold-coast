PRINTING RECOMMENDATIONS
--------------------------------------------------------------------------------

• Cards: 300gsm cardstock, print at 300 DPI, size to standard poker size (2.5" x 3.5") or European (63x88mm)
• Board: A3 or tiled A4, 200-250gsm
• Tokens: Print and glue onto 3mm plywood/cardboard or use as reference for 3D printing
• Dice: Use as reference for custom manufacturing
• Rulebook: Print double-sided on good paper, staple or perfect-bind

--------------------------------------------------------------------------------
GAME OVERVIEW (Quick)
--------------------------------------------------------------------------------

Players choose one of four Ghanaian empires, each with a unique Leader ability.
Build a 20-25 card deck from the shared pool (or pre-built faction decks).
Race tokens around the board using dice rolls + card plays.
Use Weather to slow enemies, Spies to sabotage, Medics to revive, Scorch to destroy high-value tokens, Horns to double strength.
First player to get all their tokens home to the Golden Stool wins.

Full rules are illustrated in the Rulebook folder.
